# ecView

ecView is a Python tool for viewing an ecDNA or HSR together with its 3D structure, Hi-C contacts and genomic path.

It produces a self-contained interactive HTML page. Duplicated regions can be displayed as separate copies and followed across the 3D structure, contact map and path.

## Installation

```bash
pip install git+https://github.com/Biswanath2410/ecview
```

Optional support for `.hic`, `.cool`/`.mcool` and bigWig files can be installed with:

```bash
pip install "ecview[hic,cool,bigwig] @ git+https://github.com/Biswanath2410/ecview"
```

Alternatively:

```bash
git clone https://github.com/Biswanath2410/ecview
cd ecview
pip install .
```

## Basic usage

```bash
ecview \
    --bed sample_ecDNA.bed \
    --xyz sample_xyz.txt \
    --mat sample.hic \
    -o sample.html
```

The output HTML file can be opened directly in a web browser.

Main inputs are:

- `--bed` or `--cycles`: ecDNA or HSR path
- `--xyz`: one or more 3D structures
- `--mat`: Hi-C matrix, `.hic`, `.cool` or `.mcool`
- `--contacts`: contact lists such as significant interactions
- `--genes`: gene BED file
- `--feat`: other BED features, such as enhancers
- `--track`: bedGraph, bigWig or BED tracks

Run

```bash
ecview --help
```

for all options.

## 3D structures

ecView does not reconstruct 3D structures. It visualizes coordinates generated by ec3D or other reconstruction methods.

Supported inputs include:

- `x y z` coordinates in path order
- `bin x y z`
- genomic-position tables such as `.3dg`
- PDB files

Multiple structures can be loaded with `--xyz` and compared on the same page.

If duplicated regions are not separately resolved by the input structure, their copies are displayed at the same available coordinate.

## Copy-resolved Hi-C

Reference-coordinate `.hic` and `.cool` files do not distinguish between duplicated copies of the same genomic region. By default, ecView divides the observed contact equally among the corresponding copy pairs.

Copy-aware contacts can instead be estimated with CADET Layer 1:

```bash
git clone https://github.com/Biswanath2410/cadet

ecview \
    --bed sample_ecDNA.bed \
    --mat sample.hic \
    --deconvolve \
    --cadet /path/to/cadet \
    -o sample.html
```

A matrix already represented in ecDNA path space, such as an ec3D expanded matrix or CADET `latent_X_symmetric.txt`, can be supplied directly with `--mat`.

## Interactive view

The HTML page contains linked views of the:

- 3D structure
- Hi-C contact map
- ecDNA or HSR path

Selecting a genomic bin or contact highlights the corresponding positions and duplicated copies across the views.

The contact map can be displayed in ecDNA path order, where duplicated copies remain separate, or in genome order, where their contacts are combined at the reference positions.

Genes, enhancers and genomic tracks can also be displayed. ecView supports 3D-neighbor searches, contact blocks and comparison of multiple structures.

## Examples

Example files are provided for D458, H2170, GBM39, GBM39-HSR and IMR-5/75.

### D458

D458 includes an ec3D structure, a second ec3D random start, an expanded Hi-C matrix, significant interactions, genes, enhancers and ATAC-seq.

```bash
cd example/D458

ecview \
    --bed D458_ecDNA.bed \
    --xyz D458_coordinates.txt run2=D458_run2_coordinates.txt \
    --mat D458_expanded_matrix.txt.gz \
    --contacts D458_SI=D458_significant_interactions.tsv \
    --genes genes.bed \
    --feat enhancer=enhancers.bed \
    --track ATAC-seq=D458_atac.bedGraph \
    -o D458.html
```

### H2170

H2170 demonstrates copy-aware deconvolution directly from Hi-C using CADET Layer 1.

```bash
cd example/H2170

ecview \
    --bed H2170_ecDNA.bed \
    --mat H2170.hic \
    --deconvolve \
    --cadet /path/to/cadet \
    --genes genes.bed \
    -o H2170.html
```

`H2170.hic` is not included in the repository and must be prepared from the published Hi-C data.

### GBM39 and GBM39-HSR

The same EGFRvIII amplicon can be viewed as ecDNA in GBM39 and as an HSR in GBM39-HSR.

```bash
cd example/GBM39

ecview \
    --bed GBM39_ecDNA.bed \
    --xyz ecDNA=GBM39_ec_coordinates.txt HSR=GBM39_hsr_coordinates.txt \
    --mat GBM39_ec_expanded_matrix.txt.gz \
    --contacts ecDNA_SI=GBM39_ec_significant_interactions.tsv \
    --genes genes.bed \
    -o GBM39_ec.html

ecview \
    --bed GBM39_ecDNA.bed \
    --xyz HSR=GBM39_hsr_coordinates.txt ecDNA=GBM39_ec_coordinates.txt \
    --mat GBM39_hsr_expanded_matrix.txt.gz \
    --contacts HSR_SI=GBM39_hsr_significant_interactions.tsv \
    --genes genes.bed \
    -o GBM39_hsr.html
```

### IMR-5/75

```bash
cd example/IMR575

ecview \
    --bed IMR575_HSR.bed \
    --xyz IMR575_coordinates.txt \
    --mat IMR575_expanded_matrix.txt.gz \
    --contacts IMR575_SI=IMR575_significant_interactions.tsv \
    --genes genes.bed \
    -o IMR575.html
```

## Reproducing the examples

Scripts used to prepare the example data are in `example/scripts`:

```text
run_ec3d.py
get_genes.py
get_enhancers.py
get_atac.py
run_samples.py
```

`run_samples.py` can generate ecView pages from AmpliconRepository results and the corresponding Hi-C data:

```bash
CADET=/path/to/cadet \
python example/scripts/run_samples.py data out hic.tsv --genes
```

The commands and data sources used for the analyses reported in the ecView paper are described in its Supplementary Information.

## Jupyter

ecView can also be opened from Python:

```python
from ecview import view

view(
    bed="sample_ecDNA.bed",
    xyz="sample_xyz.txt",
    mat="sample_matrix.txt"
)
```

The bundled examples use published data from D458, H2170, GBM39, GBM39-HSR and IMR-5/75. Full accession numbers and data provenance are provided in the ecView paper and Supplementary Information.
